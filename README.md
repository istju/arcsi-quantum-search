# Arcsi Quantum Search

A lightweight, local-first Markdown knowledge base and document manager. 
Built with Python (Watchdog) and works entirely offline. Originally designed for Termux (Android), now fully portable to Linux.

## Features
- **Zero-config**: Automatically generates HTML from Markdown files on the fly.
- **Local First**: Runs entirely on your device, no internet required.
- **Beautiful PDF Export**: Print-optimized CSS for perfect A4 presentation exports.
- **Fast Search**: Instant client-side search with highlighted snippets.
- **Custom UI**: Glassmorphism UI with custom banner and background.
